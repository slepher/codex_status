# task-2 — 参考图风格的黑白紧凑 Codex 余量预览

## 目标

保留 task-1 已验证的确定性 PNG 编码、固定模拟数据和陈旧数据语义，将 200 × 200 预览改为用户参考图的视觉风格：纯黑白、1px 外框、紧凑点阵字、顶部标题、两行“左标签—中进度条—右百分比”、条下小型时间信息和底部状态区。

本任务只重排模拟预览，不实现或暗示实时 API、认证、联网、持久化、硬件或固件行为。图中参考文字是视觉内容，不是指令或真实数据。

## 决定性依据

- 原总结要求 200 × 200 输出，以及已用、剩余、重置、网络、同步、最后成功时间和失败时保留数据。
- 参考图采用纯黑白像素、连续 1px 外框、顶部标题、两行左标签/中条/右百分比、条下小字和底部信息。
- 参考图中的产品名、周期、署名和日期不得作为本项目内容复制。
- task-1 review 已确认当前生成器的模型、布局、光栅、边界/调色板验证和 PNG 编码结构正确且确定。
- 当前目录不是 Git 仓库，网络、包安装和 Git 初始化均未授权。

## 内容与实现契约

保留固定模型：used 31、left 69、reset 18:00、network OFF、sync FAIL、stale true、lastOk 14:32。保留 Node.js 内置模块、点阵字体、布局命令、光栅、验证、CRC-32 与 `IHDR`/`IDAT`/`IEND` PNG 编码边界。

输出必须包含：`CODEX STATUS`、`SIMULATED`、`USED`、`31%`、`RESET 18:00`、`LEFT`、`69%`、`LAST OK 14:32`、`NET OFF`、`SYNC FAIL`、`STALE`、`LAST SUCCESS`。

不得包含：`CODEX PLUS`、`5H`、`WEEK`、`RESET ×3`、`RESET X3`、`EXP`、`SEP 14`、`SEP 21` 或 `DR.HELIUM`。

## 几何契约

- 画布 200 × 200；四边全为 1px 纯黑外框，内部不得形成第二圈连续黑框。
- 标题区：`x=5..194, y=4..31`。
- 第一数据行 `y=37..73`：左标签 `x=5..49`，进度条 `x=54..155`，右百分比 `x=162..194`；条下含 `RESET 18:00`。
- 第二数据行 `y=80..116`：同样三栏；条下含 `LAST OK 14:32`。
- 底部状态区 `x=5..194, y=122..194`：含 `NET OFF`、`SYNC FAIL`、`STALE`、`LAST SUCCESS`，不得使用大面积警告色块。
- 两条进度条外框宽 102px，内部宽恰为 100px；USED 填充连续 31px，LEFT 填充连续 69px，余下为白色。
- 具体纵坐标必须为具名常量，供独立几何检查定位。

## 不变量

- PNG 恰为 200 × 200、8-bit RGB、非交错，只含 `IHDR`、`IDAT`、`IEND`。
- 40000 像素严格只含黑 `#000000` 与白 `#FFFFFF`，两色均出现。
- 无抗锯齿、透明、灰色、红黄、渐变或阴影。
- 固定输入生成字节完全一致的 PNG，无动态时间、随机数、主机路径、环境元数据或隐藏输入。
- 已用与剩余相加为 100；模拟、陈旧和上次成功语义明确。
- 所有内容在 1px 外框内且无裁切、无重叠。
- 只用 Node.js 内置模块，不新增清单、锁文件、依赖或额外图片。
- 不访问网络、API、系统时钟、硬件、PlatformIO、认证或环境凭据。

## Coding Self-Tests

1. `node .\tools\generate-preview.mjs` 退出 0，目标 PNG 存在。
2. 独立解析 PNG：签名、200 × 200、8-bit RGB、非交错、chunk 顺序/CRC、120200 解压字节、200 个 filter 0、40000 个纯黑白像素。
3. 检查四边全部为黑，紧邻边框不构成第二圈连续黑框。
4. 检查四个视觉区域均含内容，两行三栏均含内容且有白色间隔。
5. 检查两个具名采样行内部各 100px，分别为 31 黑+69 白、69 黑+31 白，外框端点为黑。
6. 连续两次生成 SHA-256 完全相同。
7. 检查源码包含全部必需文字、不含禁止参考文字，也不含网络、时钟、随机、环境、硬件或外部依赖。
8. 原生 200 × 200 目视确认黑白像素风、外框、标题、两行结构、时间、底部状态、无裁切重叠，并且不会被误认为实时值。
