# task-3 — 保持自然高度的顶部紧凑布局

## 目标

根据用户“不需要为了占满屏幕而上下拉伸”的澄清，压缩 task-2 的纵向布局。PNG 与外框仍为 200 × 200，但所有非外框内容在 `y=124` 或更早结束；`x=1..198, y=125..198` 完全留白。

本任务不改变数据、含义、横向三栏、进度条比例、颜色、编码器或输出路径。

## 依据

- 参考图自然高度约 122px；当前内容实际从 `y=9` 延伸至 `y=182`。
- 当前标题为 `y=9..18`，第一行 `y=40..64`，第二行 `y=83..107`，状态内容分布到 `y=182`，主要块间有约 18–19px 空白。
- task-2 已验证标题左右对齐、纯黑白像素风、完整外框、双行三栏、100px 条及精确 31/69 填充、必需文字与确定性 PNG。
- 完整外框表示设备画布，不意味着内部必须占满。

## 所有权

编码工作者只可覆盖 `tools/generate-preview.mjs` 与 `artifacts/codex-quota-preview.png`。工作流由调度者管理；task-1、task-2 与全部既有审阅文件不可修改。不得新增实现、测试或参考文件，不得删除任何文件。

## 最小实现方案

保留模型、字体、绘制原语、调色板、进度条逻辑和 PNG 编码器。只缩小纵向区域、向上移动两行和状态文字；必要时只缩小状态文字字号。保留所有横向坐标。增加内容最大 y、底部留白、块间距和非外框命令两两不重叠验证。

## 几何契约

- 画布与外框：200 × 200，四边连续 1px 纯黑，无第二圈。
- 标题带：`y=5..18`。
- USED 带：`y=27..50`。
- LEFT 带：`y=56..79`。
- 状态带：`y=85..124`。
- 四带均含非外框黑色像素，其他 `y=1..124` 行不得有内容。
- 所有非外框内容实际最大 `y <= 124`；`x=1..198, y=125..198` 全白。
- 按实际黑色像素包围盒计算，三个相邻块的纵向空隙均为 `0..12px`。
- 所有非外框布局命令采用半开矩形，两两不得相交。
- 标题仍为左侧 `CODEX STATUS`、右侧 `SIMULATED` 的同一行，至少留 1px 水平间隔。
- 两条进度条外框仍为 `x=54..155`、内部 `x=55..154` 共 100px；USED 为 31 黑+69 白，LEFT 为 69 黑+31 白；纵坐标使用具名常量。

## 内容与不变量

必须保留 `CODEX STATUS`、`SIMULATED`、`USED`、`31%`、`RESET 18:00`、`LEFT`、`69%`、`LAST OK 14:32`、`NET OFF`、`SYNC FAIL`、`STALE`、`LAST SUCCESS`，且不得出现参考图身份/周期/日期/署名。

PNG 仍须为确定性的 200 × 200、8-bit RGB、非交错，只含 `IHDR`/`IDAT`/`IEND` 和纯黑白像素；无动态时间、随机、环境、网络、API、认证、硬件或外部依赖。

1. 阅读当前计划、状态、task-3、task-2 reviews 和实现，记录修改前哈希。
2. 保留横向布局与编码管线，定义四个顶部内容带。
3. 向上重排两行、时间和状态；仅必要时缩小状态字号。
4. 加入命令两两不重叠、最大 y、底部留白和实际块间距验证。
5. 生成 PNG，执行全部 Coding Self-Tests 并原生尺寸目视检查。
6. 报告路径、退出码、SHA-256、像素数、最大 y、块间距、条几何和目视结论，不提交。

1. 生成器退出 0，PNG 存在。
2. 完整回归 PNG 签名、200 × 200、8-bit RGB、非交错、chunks/CRC、120200 解压字节、200 行 filter 0、纯黑白像素、单像素外框。
3. 排除外框后断言 `contentMaxY <= 124`、底部内部 `y=125..198` 黑像素为 0、底框黑像素为 200。
4. 扫描四个内容带，断言都非空，带外无内容，三个实际包围盒间距均为 0..12。
5. 验证所有非外框布局命令矩形两两不相交，并报告命令数量与零重叠。
6. 回归标题 x=5/右边界194/同一行/不重叠，以及两行三栏与 100px 条的精确 31/69 填充。
7. 连续生成两次 SHA-256 相同。
8. 源码仅有 Node 内置模块、全部必需文字、无禁止文字或动态/外部输入；历史任务文件哈希不变。
9. 原生 200 × 200 目视确认内容自然集中在顶部约 124px，底部干净留白，未扩大块间距，全部文字可读且诚实语义清楚。
