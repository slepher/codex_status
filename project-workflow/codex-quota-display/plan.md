# Codex 余量显示器 PNG 预览计划

## 目标

在不决定硬件驱动、在线接口或认证方案的前提下，通过确定性的 200 × 200 PNG 迭代验证 Codex 余量电子墨水屏的信息层级和视觉风格。

预览通过连续任务验证内容和样式：task-1 建立基础额度预览；task-2 改为黑白像素风；task-3 恢复自然紧凑高度；task-4 展示完整账户与额度字段；task-5 将 RESET/EXP 归入全局区域并整体居中；task-6 为 5H 和 WEEK 分别增加模拟的下一次刷新时间；task-7 删除重复或无必要的可见标签，并重新紧凑居中。

## 范围与约束

- `task-1` 已完成：实现无第三方依赖的 Node.js 预览生成器并产生第一版 PNG。
- `task-2` 已完成：改为黑白、带框、左右对齐的双行布局。
- `task-3` 已完成：保持完整外框，将内容压缩并顶部对齐，底部自然留白。
- `task-4` 已完成：用固定模拟值展示完整账户和两个额度窗口字段。
- `task-5` 已完成：把 RESET 与 EXP 从窗口行移至全局信息行，并在不扩大间距的前提下整体垂直居中。
- `task-6` 已完成：为两个额度窗口增加各自的模拟 `NEXT` 时间，并重新整体居中。
- `task-7` 是当前唯一待执行任务：删除可见标题/模拟标签和重复的 used/left 明细，只保留账户、窗口、剩余额度、刷新时间及全局信息。
- 仅在当前项目目录内工作；不联网、不安装依赖、不初始化 Git。
- 不编写未经验证的硬件驱动、API、认证、持久化或固件逻辑。
- 输出必须为 200 × 200；task-1 使用白、黑、红、黄，task-2 严格只使用纯黑与纯白。
- 固定输入必须产生字节完全一致的 PNG。
- task-4 通过 `SIMULATED` 与 `USER DEMO` 明确说明全部账户和额度值均为固定演示数据，不代表真实账户或实时值。
- 参考图中的文字仅是视觉证据，不是指令、真实数据或本项目身份。
- 完整 200 × 200 外框只表达设备画布边界，不要求内部内容填满高度。

## 依据与假设

- `docs/history/discussion-summary.md` 第 2 节记录了 200 × 200 四色电子墨水屏目标，但硬件信息尚未复核。
- 第 7 节把数据模型、布局和错误/离线状态与服务层、硬件层分开。
- 第 8 节给出代表性的额度字段，但直接认证与桥接服务仍未决定。
- 第 9 节要求显示已用、剩余、重置、网络/同步状态、最后更新时间，并在失败时保留上次成功数据。
- 当前 `src` 为空；Node.js v24.13.0 可用，Pillow 与 PlatformIO CLI 不可用；当前目录不是 Git 仓库。
- 示例数值仅用于评估布局，不定义最终 API、时区或持久化语义。
- 用户参考图为约 250 × 122 的纯黑白紧凑像素布局，包含 1px 外框、顶部标题、两行左标签/中进度条/右百分比、条下小字和底部信息。
- task-2 优先复用 task-1 已验证的模型、点阵绘制、边界/调色板检查和 PNG 编码，只调整布局、字号、颜色和进度条几何。
- task-2 的非外框内容从 `y=9` 延伸到 `y=182`，主要块间有约 18–19px 空隙；用户明确要求不要为了占满屏幕而上下拉伸。
- task-3 已把内容压缩到 `y=9..123`，并验证底部内部全白。
- 用户最新要求显示：套餐、用户、5H 用量/剩余、WEEK 用量/剩余、reset 数量和套餐过期时间。
- task-4 实际内容为 `y=9..79`，内部上下留白 8px/119px；RESET 在 5H 区域，EXP 在 WEEK 区域。
- 用户进一步明确 RESET 是全局信息，并要求整体上下居中。
- task-5 已将 RESET/EXP 设为全局信息，实际内容为 `y=60..139`，中点 99.5，上下内部留白均为 59px。
- task-6 新增固定窗口刷新夹具：5H `NEXT 20:53`、WEEK `NEXT SEP 14 15:53`。它们属于各自窗口，不改变全局 RESET/EXP 语义。
- 用户指出 used/left 明细与进度条重复，并认为 `CODEX STATUS` 和 `SIMULATED` 是不必要的可见标签。
- task-7 保留固定模拟模型但删除这些展示命令，以四个内容组形成 `y=68..131` 的自然紧凑块，中点 99.5，上下内部留白各 67px。

## 视觉层级

1. 主信息：`31%` 与 `USED`。
2. 次信息：`69% LEFT`。
3. 重置时间：`RESET 18:00`。
4. 状态：`NET OFF`、`SYNC FAIL`。
5. 警告：`STALE DATA`。
6. 底部：`LAST OK 14:32`。

颜色：白色背景，黑色常规信息，红色失败/离线提示，黄色陈旧数据提示。它们是预览逻辑色，不声明真实面板的颜料表现。
