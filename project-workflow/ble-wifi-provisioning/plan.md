# 双 ROM 蓝牙首次配网计划

日期：2026-09-30。阶段：设计，尚未改 ROM、Bridge 或设备。

目标：Note4 和 1.54 在无 Wi-Fi 凭据时显示带现行 status bar 的蓝牙配网页；Bridge 的「设备」页完成 SSID/密码输入、配对、验证和设备登记。详细交互与边界见 `design.md`。

1. 先冻结双 target 的屏幕状态样稿与 BLE 配网合同；核对现有配对窗口、NVS Wi-Fi 槽位及设备页按 MAC 作用域。
2. 实现设备端配网状态机及静态屏幕，复用现有状态图标资源、BLE 服务和 Wi-Fi 槽位。先用 Fake ROM/宿主渲染检验，再**顺序**构建 Note4 与 154g；每次核对 marker、大小、SHA256 并更新 `PROGRESS.md`。
3. 实现 Bridge BLE 客户端与设备页向导；保持设备页缓存读取无副作用，提交凭据只由用户显式触发。验证配对、错 MAC、断线、错误密码、断电和重试。
4. 两台设备分别实机验收首次配网与重新配网。OTA/USB 与重启 Bridge 均按现场版本、运行数据及既有安全门槛操作；记录运行 ROM 身份与结果。

本轮仅交付设计。实施、构建、写入设备与验收均列在唯一待办 `docs/roadmap/backlog.md`。
