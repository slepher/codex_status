# AP01 App 集合更新 Bridge 接入

复用现有设备码维护 HTTP 传输；依次实现 v3 请求与身份/未知分类、AMF3/APX2 选择和预算、持久原事务恢复、application service、UI 进度/重启等待/整体回退。与固件仓库 docs/ap01-app-update-design.md 保持一致。当前仅离线，不启停或部署 Bridge、不操作设备。

## 桌面暂存策略

暂存入口按完整内容 SHA256 复用文件，总逻辑大小限制 128 MiB（包括遗留 .tmp），单包/整批原有 16/64 MiB 输入上限不变。每次暂存时扫描精确命名的缓存；没有活动回执时清理超过 24 小时的文件，复用文件刷新保留时间。任意设备存在活动回执（包括损坏文件）均保留整个缓存；终态显式归档后，下次暂存才允许过期回收。容量不足返回 app_set_cache_full，不删除待恢复包，不修改用户原始文件。未来时间戳保留，符号链接/特殊文件拒绝。此策略依赖既有单实例操作锁，不提供跨进程并发更新支持；历史回执/取消标记不属于缓存回收范围。
