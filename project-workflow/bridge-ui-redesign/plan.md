# Bridge 界面第一版改版

## 范围

- 四个 Tab 统一视觉语言；模板页保留现有功能与内容结构。
- 设备页按「当前设备与连接 → 余量/运行摘要 → Profile 与发布 → 诊断与高级操作」排序。
- 数据页先展示数据源状态与采集入口，再展示字段快照；测试 JSON 收在高级区。
- MCP 页先展示服务地址和状态，再展示 Agent 接入文本。

## 约束与验收

- 仅改 UI 的 HTML/CSS 和必要的展示文案，不改 Tauri 命令、设备协议、保存/发布行为。
- 所有现有 DOM id 与事件入口保留，避免断开动态数据与操作。
- 在 560×680 默认窗口和窄窗口下可阅读；脚本语法检查、DOM id 唯一性检查、`git diff --check`。
- 这是方向稿；后续根据实际窗口截图和使用反馈细化排版与文案。
