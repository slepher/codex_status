# 发布矩阵与 Bundle 中文字体

2026-10-11 用户授权：保留 Windows/macOS 应用及 Note4/1.54 双 ROM 发布；中文字库不内置 ROM，随完整 Bundle 发布并参与模板渲染；中文实机验收与不能正常发布的 1.54 明列缺口；Base64 复用现有库。不提交、不部署、不触发远端发布。

## 设计

- CI 分离应用平台、串行两个固件目标；从实际镜像 marker 取目标/版本，登记长度与 SHA256。发布版本是整套源码快照标签，各 ROM 保留自己的版本。任何必需任务失败阻止完整 Release。
- CSFN v1 ASCII 保持兼容；v2 在 glyph 表前添加排序的 Unicode scalar u32 表，描述符仍为 8 字节，1bpp、48 KiB 有界子集。字体只是数据，复用当前 Bundle 字体资源与同源绘制。内建字体保留 ASCII fallback，中文资产通过既有字体槽绑定；缺字统一显示 ?。
- UTF-8 字符读取、字形索引、宽度与绘制共用逻辑，设备与宿主使用相同 C++；静态/动态文本均可用。无字体时保留原 ASCII 净化语义。
- 不展开完整 CJK 字库；字符集合由生成器显式指定。先校验版本/数量/码点/长度/CRC/字形边界，后加载。ROM 排除旧 CN 字库源文件，保留旧绘制代码。

## 验证边界

生成器、Rust 验证与 C++ 加载/渲染对照；畸形码点/UTF-8、缺字、宽度、Bundle 安装恢复；既有 ASCII 回归。CI 静态检查、Windows 软件测试及可用本机构建。macOS CI、双 ROM 发布与中文实机证据未取得前保持缺口。
