# 绿灯改为数据活动指示

## Plan
用户明确要求当前ROM绿灯改为任何数据传输时闪烁。采用Wi-Fi/BLE应用层收发活动，包含HTTP请求/响应、协议分片、GATT读写/通知、UDP公告及OTA块；连接/广播等待、BOOT和USB状态本身不点亮。短活动可见脉冲，连续传输保持明暗交替，空闲自动灭。不改变正式/临时Light、配网、owner或传输成功语义。

## Tasks
- 复用ESP原生定时设施驱动LED，避免主循环/EPD阻塞延长灯态；无新增任务、协议字段或持久状态。
- 用收发入口替换现有BLE状态/USB触发点，空闲/深睡收尾灭灯。
- 定向验证短包、持续流、停止、时间回绕；构建Note4候选及资源/栈核对。暂不替换运行.83，Fake不能证明GPIO效果。
