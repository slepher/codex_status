## 模板与显示

- 变体仍使用 `codex-status-a`，独立目标 `lcd-jd9853-320x240-palette4`，320×240，`pixel_format=4bpp`、`colors=ap01-palette-v2`。仅作为 `cuktech-ap01-0041` 的软件候选，`hardware_verified=false, partial=false, ble=false, wifi=true`。0041 SIM 是页面验证载体，不是此固件身份的实机证明。
- 一字节两像素，高半字节在左；七个固定索引依次为 black/white/cyan/orange/muted/track/alert。唯一颜色表在 `src/ap01_template_display.h`，RGBA 预览与 LVGL 均从同一 RGB565 表展开。不是 RGB565 整帧，更不是把彩色画面缩放成现有 EPD 目标。
- `ring` 图元使用百分比绑定，`x/y/radius/thickness/fg/bg/when`；12 点顺时针，0% 不填、100% 填满，越界与非百分比绑定明拒。CT_RING=5 使用现有有界 CtOp 字段，不扩大持久结构；未知旧固件拒绝新图元。CTP1/ABI2 记录布局不变，目标是能力边界，旧 EPD 目标不接受 ring，不向现有设备发布该产物。
- 渲染还是同一 C++ 编译/CTP1/执行链。中文与48px数字是两份现有 CSFN v2 单色字形掩码，颜色由模板着色，随完整 Bundle 发布；不内置中文 ROM，不增加字体类型。
- 模板只绑定现有7个远端字段：5h/weekly 的 remaining、resetsAt，account.plan、bridge.label、RC；本地为 sync_hhmm/offline_mins。没有 Token 总量/历史/趋势源。
- 5h 缺失：隐藏整个组及分隔线，周额度居中放大；5h 存在：左右布局。RC 与用户名缺失按现有 when 隐藏。合法0值仍显示。源未初始化沿用现有首份快照准入，不发空字段包。
- 本变体以当前周额度账号为布局基线；现有 weekly 选择器对长窗口的兼容语义不在此改写。月额度账号专用文案/变体尚未验收，不能把静态“7天”文案推广为全部套餐。

## 原有界面与平台上下文

原厂重建 UI 使用条件有向边，不能替换成全局固定页面数组。正转原来将进入 Pet 的边插入 Profile 全部模板；反转 Pet 的边先进入最后一个模板。于是已配网常见路径为 Weather → 模板1…模板N → Pet，反向对应返回；无底座/无C1/C2/未配网时仍由原有规则决定原厂前页。首次指南原有旋钮门控继续生效。

`Ap01TemplatePage` 只记录显示焦点与模板位置，不复制 Profile、数据、owner 或凭据。模板内部切换先调用现有平台的本地原子激活回调；确认成功后才改变位置，失败/结果未知保持原页，回调负责原事务查询，不生成新ID假成功。全部1–8项都参与，没有 enabled 子集。离开到原厂页保留最后 active context；返回同项不额外创建上下文，A→B→A 则仍走平台激活并产生不同上下文。

网络回调更新最新快照/投递 UI 消息，禁止操作 LVGL。只有原厂 UI 线程渲染与提交。焦点在原厂页时后台数据不改焦点；在模板页时按新数据重排。原厂 boot/屏保/指南/详情分发在模板绘制之前，充电弹窗/系统覆盖层在其后；OTA/配对/维护更高优先级。短按不新增网络动作；返回和原厂3秒回主页退出模板焦点。同步时间必须来自 AP01 自身成功同步，不能复制 Note4 数据。

## LVGL 所有权与预算

`Ap01TemplateImageCandidate` 按实际绘制分配38464 B（38400 B像素＋64 B LVGL调色板）；渲染完全成功后 `Commit` 移交所有权，失败由调用方 Discard。常驻只保留一个已提交帧；替换时允许旧＋新两帧瞬时共存，成功换源后释放旧帧。对象删除前清缓存，释放须在 UI 线程。没有新增153600 B RGB565或307200 B ARGB整帧。

Commit成功只表示UI接收了完整候选与所有权；不能直接用于协议displayed回执。实际显示完成仍须由目标LVGL/驱动提交结果报告，应用提交与物理显示成功分开。

NuttX LVGL9 的 I4 解码器按行需要1280 B ARGB暂存，使用专用 image-cache allocator；默认cache=0会拒绝分配并黑屏。接入要求缓存预算至少容纳这一行及分配器元数据；隔离SIM首次使用时按需开4096 B，已用真实像素验证。通用 sink 在禁用cache时明确拒绝提交，不能报显示成功。不是任意修改原厂全局缓存的授权；真实目标按实际 LVGL 版本/BSP预算落地。

## 视觉精修合同（2026-10-18）

调色板修订为 `ap01-palette-v2`：0–6 仍为模板语义色，7–15 仅由渲染器用于边缘覆盖率；源模板不能指定这些内部颜色索引。所有16项使用同一RGB565表，宿主PNG、行转换和LVGL I4一致。v1能力字符串明确拒绝，未部署候选不保留隐式兼容。像素缓冲仍38400 B、调色板仍64 B。

CSFN v3 字形为行对齐alpha4覆盖率（16级），绘制时按模板前景/背景混合并量化到调色板；透明背景读取当前目标像素。Unicode码点/度量与v2一致，字体仅作为完整Bundle数据，未内置ROM。AP01须明确声明 `bundle_font_protocol=3`；EPD拒绝alpha4且不得声明3。1bpp时钟局部窗口API不接受alpha4。新字段使用字体视图的尾部空间，不增加CTP1持久记录；仍需真实目标编译确认结构与栈。

圆环每像素4×4覆盖率采样，圆周内外沿及百分比端点均平滑；0/100无多余端点。最大当前半径61，最多123×123×16=242064次距离检查，atan2只在环内采样执行。仅标量栈局部变量，未申请超采样整帧；实际MCU耗时未知。标签改为雅黑UI 13px，主数字Bahnschrift 48px、5h数字30px，标题/套餐/百分号统一使用资产字体。周重置时间移至圆环内，双窗口底部文案上移避免穿过弧线。
