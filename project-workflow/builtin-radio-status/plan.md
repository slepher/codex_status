# 内置页无线状态

2026-10-26 用户要求：仅会休眠设备的默认页/错误页显示 Wi-Fi、蓝牙状态。

沿用 ESP32 墨水屏内置绘制与 networkGlyph 有界重绘，不覆盖用户模板，不修改 AP01。错误文字预留底部两行；无模板默认页与旧 usage fallback 同样显示。Wi-Fi 使用现有独立 phase，BLE 使用实际射频开关；最终休眠画面明确表示无线关闭。状态变化不得延长 PowerPlan/BOOT 或增加无线会合。

验证生产绘制代码的文字与边界、射频变化触发有界重绘；编译书桌屏目标、匹配 ELF 栈审计、哈希/marker 核对。直接 OTA 仅单次上传，随后认证镜像哈希；模板修复保持 quad/mini 顺序，完整 Bundle 单独发布。
